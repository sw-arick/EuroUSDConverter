# USD ↔ EUR Currency Converter

A simple Python program that converts between US Dollars (USD) and Euros (EUR).

## Features

- Convert USD to EUR
- Convert EUR to USD
- Simple command-line interface
- Uses functions for currency conversion

## How to Run

Make sure Python is installed, then run:

```bash
python index.py
```

Follow the instructions in the terminal to enter the amount and choose the conversion.

## Note

The exchange rate is manually defined in the program and may not reflect the current market rate.
